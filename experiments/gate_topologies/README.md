# Gate-level topology study

**Does the end-to-end observation flow hold across different MC bit locations?** Eight target workspaces vary column, row and MixColumns multiplier roles while sharing the reference design.

## Start here

Run from the ASAL repository root in the installed Python environment:

```sh
make gate-smoke
make evidence-verify
```

## Files and outputs

`shared/` holds templates and bridge code; `cases/` holds eight target-specific inputs, DFT settings, netlists and recorded outcomes. `scripts/` generates or schedules cases. `tests/` checks infrastructure and recorded fixtures.

## Scope

Record tests read discovery and solver transcripts from the canonical `evidence/source/extra_exp1/` archive. Small case-local scan-path reports and terminal evaluator summaries are also tracked explicitly; ignored workstation outputs are not test prerequisites.

Existing terminal records are not regenerated by smoke tests. Case generation requires evaluator inputs; do not overwrite recorded cases casually. EDA scripts require `ASAL_LIBRARY_DB`.

See the [experiment index](../README.md), [execution guide](../../docs/EXPERIMENTS.md) and [recorded evidence](../../docs/EVIDENCE.md).
